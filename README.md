# champion-c

A collection of simple, fundamental C programs created for practicing basic syntax, control flow, logic, and problem-solving.

---

##What's Inside

This repository features basic C implementations covering core concepts:

* **Basics & Syntax:** "Hello World", variable usage, formatted input/output (`printf`, `scanf`).
* **Control Flow:** Conditional statements (`if-else`, `switch`) and loops (`for`, `while`, `do-while`).
* **Functions & Scope:** Modular programming using custom functions and standard C libraries.
* **Arrays & Strings:** Manipulating 1D/2D arrays and common string utility operations.
* **Pointers & Memory:** Basic pointer arithmetic and dynamic memory allocation.
