## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it directly. 

* **Where to report:** Open a private security advisory on the repository or contact the maintainer directly via GitHub profile details.
* **What to include:** Please provide a summary of the vulnerability, steps to reproduce, and the potential impact (especially regarding memory safety, buffer overflows, or pointer issues in C).
* **Response time:** You can expect an initial response within a few days acknowledging the report.

Thank you for helping keep this project safe!
